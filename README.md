# Carte Nere: modalità Bot

Contiene 800 carte bianche e 231 carte nere.

## Regole a due
- Ogni persona gioca una risposta.
- L'app aggiunge 3 risposte casuali dei bot.
- Le 5 risposte sono mescolate.
- Entrambi votano in segreto.
- Ogni voto vale 1 punto per il proprietario della risposta.
- Se viene votato un bot, il punto va ai bot.

## Pubblicazione gratuita
Carica tutta la cartella su:
- GitHub Pages
- Cloudflare Pages
- Netlify Drop (piano gratuito)

Poi apri il link HTTPS sui due telefoni.
